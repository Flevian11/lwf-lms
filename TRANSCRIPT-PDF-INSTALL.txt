Learn With Flevian LMS - Assignment Transcript PDF v1

This patch changes graded assignment transcripts from HTML files to premium A4 PDF files.
It also changes student transcript actions to Download transcript and records transcript downloads in the audit log.

Apply directly to the project root, then run:

composer update dompdf/dompdf --with-all-dependencies
php artisan optimize:clear
npm.cmd run build

Existing graded submissions should be re-graded once to regenerate their transcript as PDF. Example:

php artisan assignment:grade 1 85 --feedback="Good work. The Git workflow is clearly explained and the evidence is provided."

Do not add --graded-by for now; the current system intentionally leaves it unset until admin/instructor pages exist.
